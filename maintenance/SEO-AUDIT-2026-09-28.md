# SEO and public-page audit — 28 September 2026

## Findings and changes

- Search results already returned the homepage and the old `/termos` URL. The
  latter returned 404. `/termos` and `/privacidade` now permanently redirect to
  the current legal pages.
- The sitemap previously contained only the homepage and contact page, using
  the redirecting non-www hostname. It now contains ten public pages plus all
  published event pages, excludes quarantine, uses the www production hostname,
  and refreshes hourly. Validation found 1,668 unique URLs.
- Public pages now have canonical URLs, individual titles/descriptions and
  social metadata. Event metadata excludes inline data images and does not
  claim poster dimensions. Event URLs are encoded once; Next supplies decoded
  route parameters.
- Event title links expose normal `href` URLs while retaining the detail modal
  on an ordinary click. Modifier clicks can open the standalone page.
- The homepage includes WebSite structured data. Events with known dates include
  SportsEvent structured data using published dates and location labels. No
  ticket prices, availability, exact start times or addresses are invented.
- Personal, settings, authentication and admin pages have noindex metadata.
  API responses have X-Robots-Tag, and API paths are excluded in robots.txt.
- ICO now contains 16/32/48/64 px variants; the 192 px PNG, Apple icon and PWA
  icons remain available. Favicon URLs are stable.
- Privacy text now reflects Clerk, Neon/PostgreSQL, Vercel, optional email and
  calendar/location integrations. It distinguishes technical/legacy statistics
  from anonymous data and does not claim that every login is OAuth. The current
  frontend does not mount the detailed analytics tracker.
- Controller identification appears only where needed in the privacy policy;
  the public contact method is the form. Personal email is not printed there.
  Legal review dates are fixed to the actual revision date.

## Validation

- 177 automated tests passed, along with lint and production compilation.
- `maintenance/verify-seo.mjs` checks public HTTP responses, canonical URLs,
  headings, redirects, private-page noindex, sitemap entries, sample event
  pages, icons and manifest. Set `SEO_TEST_URL` to test a deployment.
- Calendar/modal behavior passed at 320, 390 and 430 px after the link change.
- Privacy, terms and contact passed browser checks at 390 px: no horizontal
  overflow, runtime errors, public personal email or analytics-track requests.

## Limits and follow-up

- Search presence was observed; rankings, Google-specific index coverage and
  Search Console ownership were not accessible. Submit the canonical sitemap
  in the owner's Search Console and request recrawling of key pages. No promise
  of indexing, ranking, favicon display or rich-result eligibility is implied.
- The site is an aggregator. Some event locations are only locality labels;
  structured data intentionally omits unverified postal addresses/offers. Check
  representative pages with Google's Rich Results Test before claiming enhanced
  event-result eligibility.
- The contact page and its privacy notice were tested, but no real message was
  sent. Email delivery and sender-domain configuration still need an authorized
  end-to-end test. The backend currently falls back to Resend's test sender if
  no dedicated implementation is configured.
- This is a technical and factual review, not a legal compliance certification.
  Contractual transfer safeguards, provider retention and operational handling
  of data-subject requests need confirmation by the controller. Do not re-enable
  persistent behavioral analytics without an appropriate consent review.
